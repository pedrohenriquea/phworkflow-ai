# Examples

Casos reais de aplicação dos playbooks deste repo.

## Como contribuir

Quando aplicar o playbook em um projeto real e descobrir algo útil (padrão, prompt, lição aprendida), documente aqui.

### Estrutura sugerida por exemplo

```
examples/[nome-do-caso]/
├── README.md           # contexto: que projeto, que feature, o que aprendeu
├── spec.md             # spec real (anonimizada se necessário)
├── plan.md             # plano técnico
└── retrospectiva.md    # o que funcionou, o que não, ajustes propostos
```

## Propósito

Examples não são exemplos didáticos genéricos. São registros de **aplicações reais** que ajudam o time a:

- Calibrar expectativas (quanto tempo levou? quantos chats?)
- Identificar padrões recorrentes
- Refinar templates e prompts com base em uso real
- Onboardar novos devs com casos concretos
